## 決めたこと

- ヘッダー3数字: 未確定 = `status <= 1` / 図面未反映 = `status >= 2 && !drawn` / 未質問 = `!done`
- JSON I/O: ヘッダーメニュー。タブ骨組みの直後に入れる
- 写真・PDF: 決定/質問/アイデア/議事録に添付。図面・見積・過去資料は資料タブ。Supabase Storage `iezukuri`、1ファイル10MB
- 共有: white-tee-ec の `iezukuri_*`。家は1件固定。ログインも世帯コードもなし
- kanemasa-fabric-os は触らない
- RLS は anon 全開（世帯UUIDが秘密）。white-tee-ec を公開ECにする前に締める
- 議事録: `raw`（原文）を持つ。原文から5項目を LLM で抽出する。抽出結果は手編集できる
- 抽出の手段: Anthropic（`claude-sonnet-5`）。キーはサーバーだけ。ライブラリは足さない
- Tailwind v4（`@theme`）。トークンは `src/index.css`
- 決定フィルタ: 状態（すべて/未確定/図面未反映）と大分類は2軸。外構のときだけエリア別トグル
- `due` が過ぎた・14日以内はグループの外の上部へ出す（複製しない）
- カード展開は複数同時OK。削除は confirm。新規は各タブ先頭
- JSON読み込みは置換（確認ダイアログあり）。マージしない
- 食洗機の初期 status は確定(2)。「譲れない」は本文に残す
- 質問→決定: 大分類を選ばせる。status は検討中。質問は削除
- 議事録の行送り: 改行=1件。決定の大分類は一括。status は仮(1)
